How WiFi QR Codes Actually Work

A WiFi QR code isn't magic — it's just a QR code encoding a short, standardized text string that phone camera apps know how to parse. Understanding that string demystifies both what the code can do and where its limits are.

The Format Hiding Inside the Code

Every WiFi QR code encodes a string that looks roughly like WIFI:T:WPA;S:MyNetwork;P:MyPassword;H:false;;. Each letter is a field: T is the security type, S is the network name (SSID), P is the password, and H is whether the network is hidden. Camera apps on modern phones recognize this exact prefix and format, and when they see it, they offer to join the network directly instead of just opening a link or showing text — that's the entire trick, no proprietary technology involved.

Why the Security Type Field Matters

The T field tells the phone which authentication method to use when connecting — WPA/WPA2 is the standard for the vast majority of home and office routers today, WEP is an old, weak standard still found on some older hardware, and "nopass" means the network is fully open with no password at all. Getting this field wrong means the phone will attempt to connect the wrong way and fail, even if the network name and password themselves are typed correctly.

Tip: Special characters in your network name or password — like semicolons, commas, or backslashes — need to be escaped with a backslash inside the encoded string, since those characters are also used as field separators. A generator handles this automatically, but if you're ever typing the raw string by hand, that's the detail that trips people up.

Hidden Networks Work Differently

A visible network broadcasts its name constantly, so a phone can just show it in a list of nearby networks to join. A hidden network doesn't broadcast its name at all — the phone has to already know the exact name to look for it. That's what the "hidden network" flag in the QR code does: it tells the phone to actively search for and connect to a network with that specific name, rather than expecting to find it listed among nearby options.

When It's Actually Safe to Share

A WiFi QR code is functionally equivalent to writing your password on a piece of paper — anyone who scans it can join your network, and there's no way to revoke access to a single scan once it's out there. It's genuinely convenient for a home network, a small office, or a guest network you don't mind sharing broadly, but printing one publicly (say, on a café menu board) means anyone walking by can capture it, not just paying customers standing at the counter.

FAQ

How does scanning this actually connect someone to WiFi? This QR code encodes your network name and password in a standard format that iPhone and Android camera apps recognize automatically — scanning it prompts the phone to join the network directly, without anyone having to type the password by hand.

Is my WiFi password sent anywhere when I generate this? No — the QR code is generated entirely in your browser, so your network name and password never leave your device or get sent to a server.

Will this work with any phone? Most modern iPhones (iOS 11+) and Android phones (10+) recognize WiFi QR codes directly in their built-in camera app. Older devices may need a separate QR scanner app instead of the native camera.

What does the "hidden network" option do? Turn it on only if your WiFi network doesn't broadcast its name publicly — it tells the scanning device to search for a hidden network with the exact name you entered instead of picking it from a visible list.
