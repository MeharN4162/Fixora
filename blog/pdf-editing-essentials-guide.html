PDF Editing Essentials: Crop, Rotate, Grayscale, Watermark, Number

Most everyday PDF edits fall into one of a handful of categories. Here's what each of the five most common ones actually does, and when it's genuinely worth doing.

Cropping a PDF

Cropping trims away unwanted margins or edges from a page — useful for scanned documents with excess white space, or for isolating one section of a page. A locked aspect ratio keeps every page consistent when applying the same crop across a whole document, rather than trimming each page to a slightly different shape.

Rotating Pages

Rotation fixes pages that were scanned sideways or upside down. Individual pages, a selection, or the entire document can typically be rotated independently — useful for a mixed-orientation scan where some pages were fed into a scanner the wrong way while others weren't. A proper rotation permanently changes the page's actual orientation data, so it displays correctly for anyone who opens the file afterward.

Converting to Grayscale

Grayscale conversion strips color from a PDF, which matters most for printing costs — color ink and toner cost significantly more per page than black ink, and printers often use color cartridges for any page with even a small amount of color content. A true black-and-white conversion (rather than just grayscale) uses a threshold setting to push everything to pure black or white, useful for maximizing contrast on text-heavy scans.

Tip: If you print the same multi-page document repeatedly for internal use, converting it to grayscale once and reusing that version can add up to meaningful savings on ink over time.

Adding a Watermark

A watermark stamps text or an image across every page — commonly used to mark a document as DRAFT, CONFIDENTIAL, or to add a company name. Keeping opacity in a moderate range (roughly 10-30%) makes the watermark clearly visible without making the underlying content hard to read.

Adding Page Numbers

Page numbering adds a consistent number to each page, with control over position, format, and starting number. Skipping the first page is a common choice for documents with a cover page, since a visible page number on a title page can look out of place.

FAQ

Why would I convert a color PDF to grayscale before printing? Color ink and toner cartridges cost significantly more per page than black-only printing, and most printers automatically use color cartridges for any page containing color content, even a single colored logo. Converting a document to grayscale before printing forces true black-and-white output, which can meaningfully cut printing costs for anything printed regularly or in bulk.

Does rotating a PDF page permanently change the file, or just how it displays? A proper PDF rotation tool changes the file's actual page orientation data, not just a temporary display setting in one viewer. Once rotated and saved, the page will display correctly right-side-up in any PDF reader, on any device — it isn't a per-viewer setting that resets when someone else opens the file.

What's a sensible watermark opacity so it doesn't obscure the content underneath? Somewhere in the 10-30% opacity range is typical — enough to be clearly visible and serve its purpose (marking a document as DRAFT or CONFIDENTIAL, for example) without making the underlying text hard to read. Much higher than that starts to interfere with legibility, especially over dense text.

Why would I want to skip page numbering on the first page of a document? The first page is often a cover page or title page, where a visible page number can look out of place or unprofessional. Many page-numbering conventions start the visible numbering on page 2 (sometimes still counting the cover as page 1 internally) to keep the cover page clean.
