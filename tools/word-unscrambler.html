Word Unscrambler & Anagram Solver

Enter scrambled letters and find every real word you can make, with Scrabble scores.

How to Unscramble Letters

  1. Type the letters you want to unscramble.
  2. Results appear instantly, grouped by word length, with full anagrams shown first.
  3. Each word shows its Scrabble point value.

Frequently Asked Questions

What word list does this check against?

A list of roughly 9,300 common English words drawn from real word-frequency data, rather than a tiny hand-picked list — so it covers everyday vocabulary well, though it won't include every obscure word a full Scrabble dictionary would.

What's the difference between the full anagrams and the other results?

A full anagram uses every single letter you entered, rearranged. The other results use only some of your letters — both are useful, but full anagrams are the stricter, classic definition of an anagram.

Are the Scrabble scores accurate?

Yes — each letter's point value matches the standard English-language Scrabble tile values exactly (for example Q and Z are worth 10 points, while common letters like E and A are worth 1).

Is my input sent anywhere?

No — the word list is built into this page and everything is checked entirely in your browser using JavaScript, so nothing you type is ever sent to a server.
