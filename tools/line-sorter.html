Line Sorter & Randomizer

Sort, shuffle, or de-duplicate a list of lines instantly.

How to Sort or Randomize Lines

  1. Paste your list, one item per line, into the box.
  2. Click any button to sort alphabetically, by length, numerically, shuffle randomly, remove duplicates, or reverse the order.
  3. Copy the result with the "Copy Result" button.

Frequently Asked Questions

How does the numeric sort work if my lines aren't all numbers?

Lines are compared by the first number found at the start of each line; lines with no leading number are treated as the lowest value and sorted to the top. This is useful for lists like "12 apples" or "3. Item three" where you want numeric rather than alphabetical order (which would otherwise put "10" before "2").

How is shuffling actually randomized?

It uses the Fisher-Yates shuffle algorithm, which produces a genuinely uniform random permutation, powered by the Web Crypto API's crypto.getRandomValues() rather than Math.random() for better randomness quality.

Is removing duplicates case-sensitive?

By default yes — "Apple" and "apple" are treated as different lines. Turn on "Ignore case" to treat them as duplicates regardless of capitalization, keeping only the first occurrence.

Is my text sent anywhere?

No — all sorting, shuffling, and de-duplication happens entirely in your browser using JavaScript, so your text is never sent to a server.
