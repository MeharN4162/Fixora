Frequently Asked Questions

What's the difference between the host and the origin?

The host is just the domain name and port, like example.com:8080. The origin includes the protocol as well — https://example.com:8080 — and it's the origin, not just the host, that browsers use to decide whether two pages are allowed to interact under same-origin security rules.

Why do some query parameters show up percent-encoded and others don't?

Only characters that aren't safe in a URL get percent-encoded — spaces, ampersands, and similar reserved characters. Letters, numbers, and a handful of safe punctuation marks pass through unencoded, which is why a query string can look like a mix of plain text and %XX sequences in the same value.

Can a URL have the same query parameter more than once?

Yes — a query string can legally repeat a parameter name, like ?tag=red&tag=blue, and different servers and frameworks handle this differently: some treat it as an array, others just keep the first or the last value. This tool lists every occurrence separately so you can see exactly what's actually present in the URL.

Is my URL sent anywhere when I paste it in?

No — this tool uses your browser's own built-in URL parsing, so everything happens locally and nothing is ever sent to a server, even if the URL contains sensitive query parameters like a token or session ID.
