How to Reorder PDF Pages

  1. Upload your PDF — every page renders as a thumbnail labeled with its position and original page number.
  2. Press and hold a thumbnail's grip handle and drag it to a new spot — or use the small up/down buttons if you'd rather not drag.
  3. Use a thumbnail's delete button to remove that page, or its duplicate button to insert a copy right after it.
  4. Need the whole document backwards? Click "Reverse Page Order" to flip every page's position in one click.
  5. Watch the "Position N (was page M)" label update as you move pages around, confirming the new order.
  6. Click "Save Reordered PDF" and download the result.

Frequently Asked Questions

Can I drag and drop pages to reorder them?

Yes — press and hold any page thumbnail's grip handle and drag it to a new position; the order updates live as you move it and the position labels renumber automatically. Small up and down buttons remain on each thumbnail too, in case you'd rather not drag.

How do I know what the new page order will be before saving?

Each thumbnail's label shows both its current position and its original page number (e.g. "Position 3 (was page 7)"), so you can confirm the exact order before clicking Save.

Does reordering affect page rotation or content quality?

No — pages are copied directly from the source PDF's structure using pdf-lib rather than being re-rendered, so their rotation, selectable text, and image quality all stay exactly as they were.

Can I move a page to the very top or bottom quickly?

Yes — drag a thumbnail's grip handle all the way to the start or end of the grid and drop it there in one motion. The up and down buttons still move a page only one position per click, so dragging is faster for big jumps.

Is there a limit to how many pages I can reorder?

No hard limit, but every page is rendered as a thumbnail image in your browser when the file loads, so very long documents may take longer to load and use more memory since everything runs locally on your device.

Can I delete a page while reordering?

Yes — each thumbnail has its own delete button that removes just that page from the final PDF. The remaining pages shift up and renumber automatically, and the button disables itself once a single page is left, since a PDF can't have zero pages.

Can I duplicate a page instead of just moving it?

Yes — each thumbnail's duplicate button inserts an exact copy of that page directly after it, keeping the original's selectable text, images, and rotation intact. The new copy is labeled "· copy" so you can tell it apart from the page it came from.

Is there a quick way to reverse the whole page order?

Yes — click "Reverse Page Order" above the Save button to instantly flip the entire document so the last page becomes the first and vice versa, without dragging every thumbnail individually.
