Cron Expression Parser

Parse a cron expression and see exactly when it will next run.

How to Parse a Cron Expression

  1. Type or paste a 5-field cron expression.
  2. The field breakdown and next several run times appear instantly.

Frequently Asked Questions

What do the 5 fields in a cron expression mean?

In order: minute (0–59), hour (0–23), day of month (1–31), month (1–12), and day of week (0–6, where 0 is Sunday). Each field can be a specific value, a *, a range like 1-5, a list like 1,3,5, or a step like */15.

What happens when both day-of-month and day-of-week are restricted?

Standard cron treats this as an OR — the job runs if either condition is true, not only when both match. This matches the behavior of cron on Linux and most job schedulers.

Are the next run times shown in my local time zone?

Yes — they're calculated using your browser's local clock and time zone. If the actual server running this cron job is in a different time zone, its real run times will differ accordingly.

Is my cron expression sent anywhere?

No — parsing and the next-run calculation both happen entirely in your browser using JavaScript, so nothing you enter is ever sent to a server.
