How to Resize an Image

  1. Click the upload area or drag in a JPG, PNG, or WebP image — or several images at once to switch into batch mode. Pixel dimensions load automatically.
  2. Choose "Exact Pixels" to type a specific width and height (or tap a quick preset like Instagram Post or YouTube Thumbnail to fill them in instantly), or "Percentage Scale" to scale by a percentage (1–200%).
  3. In Exact Pixels mode, leave "Lock aspect ratio" checked so changing width automatically recalculates height (and vice versa).
  4. Pick an Output Format — Same as source, PNG, JPEG, or WebP — and drag the Quality slider if you chose JPEG or WebP.
  5. Click "Resize Image" (or "Resize All Images" in batch mode), then download the result — each file gets its own Download button in batch mode.

Frequently Asked Questions

Can I make an image larger than its original size?

Yes - the percentage slider goes up to 200%, and you can also type pixel dimensions larger than the original in Exact Pixels mode. Keep in mind that enlarging a raster image doesn't add real detail; the browser's high-quality smoothing just interpolates between existing pixels.

What happens if I uncheck Lock aspect ratio?

You can then set width and height independently, which will stretch or squash the image if the new ratio doesn't match the original - useful for fitting a specific banner or thumbnail size, but it will distort the image's proportions.

What do the quick preset buttons do?

Each preset button (like Instagram Post 1080 × 1080 or YouTube Thumbnail 1280 × 720) instantly fills the Width and Height fields with that exact pixel size in Exact Pixels mode. You can still edit the numbers afterward, or uncheck Lock aspect ratio first if you want to type your own custom dimensions instead.

Can I resize multiple images at once?

Yes - select or drag in more than one image and the tool switches to batch mode. The same Width/Height (or Percentage), Output Format, and Quality settings are applied to every image, and each one gets its own Download button once processed, since there's no zip file involved. In Exact Pixels mode the identical width and height are applied to every file, which can stretch images whose original ratio differs from the first image loaded; Percentage Scale mode avoids this because it scales each image relative to its own original dimensions.

What output format will my resized image download as?

Choose from the Output Format dropdown: "Same as source" keeps your original file's format (JPG stays JPG, PNG stays PNG, WebP stays WebP), or you can force the output to PNG, JPEG, or WebP regardless of what you uploaded. For JPEG or WebP output, the Quality slider controls the compression level passed to the browser's encoder.

Does resizing reduce file size the same way compression does?

Not necessarily - resizing changes the pixel dimensions, while file size mainly depends on quality/compression settings. A smaller image will usually produce a smaller file, but for precise file-size control, use Fixoona's Image Compressor instead, which keeps dimensions fixed.

Is my image uploaded to resize it?

No. The resize (and any format conversion) is performed locally with the Canvas API's drawImage() scaling and toBlob() encoding - your files stay on your device throughout, even in batch mode.
