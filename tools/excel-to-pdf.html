Excel to PDF Converter

Convert an .xlsx or .xls spreadsheet to PDF using your browser's own print engine — choose portrait or landscape, fit wide tables to the page, and combine multiple sheets into one file.

📤
Click to upload or drag an .xlsx / .xls file here Nothing is uploaded to a server — everything happens in your browser

How it works: your spreadsheet is parsed and rendered as a table right in your browser, then handed to your browser's built-in "Print to PDF." Clicking Save as PDF opens the print dialog — choose "Save as PDF" as the destination.

How to Convert Excel to PDF

  1. Click the upload area and choose your .xlsx or .xls file, or drag it in.
  2. If the workbook has more than one sheet, check which one(s) to include in the Sheets to Include checklist — checking more than one combines them into a single PDF, each starting on its own page.
  3. Set Page Orientation to Portrait or Landscape, and turn on "Fit table to page width" if a wide table is running off the edge.
  4. Review the table preview to make sure it looks right.
  5. Click Save as PDF and choose "Save as PDF" as the destination in the print dialog.

Frequently Asked Questions

Does this preserve my spreadsheet's formulas and formatting?

Formula results are shown (the calculated values stored in the file), not the formulas themselves, and basic table structure is preserved — but complex formatting like cell colors, merged cells, or charts may not carry over exactly, since the sheet is converted to a plain HTML table before printing.

My workbook has multiple sheets — which ones get converted?

Use the sheet checklist that appears after uploading to choose which sheet or sheets to include — only the first sheet is checked by default. Check more than one and they're combined into a single PDF, each sheet starting on its own printed page.

Why does clicking Save as PDF open my browser's print dialog?

This tool hands the rendered table to your browser's own "Print to PDF" feature rather than trying to hand-build a PDF layout engine — it's the same reliable rendering engine that prints any web page, so choose "Save as PDF" (or "Microsoft Print to PDF" on Windows) as the destination in that dialog.

Does it support the older .xls format, or only .xlsx?

Both — the underlying parser reads the modern .xlsx format as well as the legacy .xls format, so you don't need to convert older files first.

What do the Page Orientation and "Fit table to page width" options do?

Page Orientation sets the printed page to Portrait or Landscape by writing an @page CSS rule the browser's print engine respects — pick Landscape for wide tables with many columns. "Fit table to page width" shrinks the font size and forces the table to a fixed layout at 100% width so it doesn't get cut off at the page's right edge instead of overflowing onto extra printed pages.

What do the numbers next to each sheet name mean?

Each sheet is listed with its used range as rows × columns, so you can tell at a glance how large a sheet is before deciding whether to include it — a sheet showing (200 × 15), for example, has 200 rows and 15 columns of data.

Is there a faster way to check or uncheck every sheet?

Yes — use the "Select All" or "Select None" links above the sheet checklist instead of clicking each checkbox individually.
