Mock JSON Data Generator

Build a schema and generate realistic fake JSON test data instantly.

How to Generate Mock Data

  1. Name each field and pick its data type.
  2. Add as many fields as you need.
  3. Set how many records to generate, then click "Generate JSON."

Frequently Asked Questions

Is this real, usable-looking data or obviously fake placeholders?

It's randomly assembled from real first names, last names, cities, and sentence fragments, so it looks like plausible, realistic test data rather than generic placeholders like "test1," "test2" — useful for populating a UI or testing how your code handles varied input.

Are the generated UUIDs valid?

Yes — they're real, correctly formatted UUID version 4 values, generated using your browser's cryptographically secure random number generator with the proper version and variant bits set.

Can I customize which fields are generated?

Yes — add as many fields as you need, name each one whatever you'd like, and choose its data type from the dropdown. The schema you build is used to generate every record.

Is any of this data real or does it come from a real person?

No — every value is randomly assembled from generic word lists built into this page. Names, emails, and other fields are not tied to any real individual, and everything is generated locally in your browser.
