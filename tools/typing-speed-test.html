How to Use the Typing Test

  1. Click into the input box and start typing the passage shown.
  2. The timer starts on your first keystroke.
  3. Finish typing the whole passage to see your final WPM and accuracy.
  4. Click "New Passage" to try again with a different passage.

Frequently Asked Questions

How is WPM (words per minute) calculated?

This tool uses the standard typing-test convention of treating every 5 characters typed (including spaces) as one "word," then divides that by the time elapsed in minutes. This is the same method used by most typing test sites, so results are comparable.

How is accuracy calculated?

Accuracy is the percentage of characters you typed correctly compared to the target passage, checked position by position. Typing a wrong character lowers accuracy even if you don't go back and fix it.

Why can't I paste the passage instead of typing it?

Pasting is disabled on purpose — the entire point of a typing test is measuring how fast you can actually type, so allowing a paste shortcut would make the result meaningless.

Is anything I type saved or sent anywhere?

No — the timer, comparison, and scoring all happen entirely in your browser using JavaScript. Nothing you type is stored or sent to a server.
