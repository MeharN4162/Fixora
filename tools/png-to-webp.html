How to Convert a PNG to WebP

  1. Click the upload area or drag in one or more PNG files — select multiple files at once to batch convert.
  2. The tool briefly checks whether your browser can encode WebP images, warning you if it can't.
  3. Adjust the "WebP Quality" slider (30–100%, default 90%), or check "Lossless" for pixel-exact output — transparency is kept either way.
  4. With a single file, compare the PNG Size and WebP Size stats and click "Download WebP"; with multiple files, download each result from its own row.

Frequently Asked Questions

Does converting to WebP keep my PNG's transparency?

Yes. Unlike the PNG-to-JPG tool, this converter draws your image straight onto the canvas without filling a background color first, so transparent and semi-transparent pixels stay transparent in the exported WebP.

What if my browser can't export WebP?

The tool runs a quick encode test as soon as the page loads. If your browser can't produce WebP output, the upload area is marked disabled and a message tells you to try a recent version of Chrome, Edge, or Firefox instead.

How does the Quality slider affect a PNG source?

It sets the lossy WebP compression level from 30% to 100%. Because PNG source images are often graphics or screenshots rather than photos, you may be able to drop quality quite a bit before artifacts become noticeable - watch the live preview as you drag.

What does the Lossless toggle actually do?

It switches the canvas encoder's quality argument to exactly 1.0, which instructs the browser's WebP encoder to use its lossless mode instead of lossy compression - verified by round-tripping a converted file back through an image decoder and comparing every pixel to the source, with zero differences. The Quality slider is disabled while Lossless is on, since there's no quality trade-off to make in lossless mode.

Why is my WebP file sometimes bigger than expected?

PNGs with flat colors or few tones can already be very small, so re-encoding as lossy WebP at a high quality setting doesn't always shrink them further, and Lossless mode in particular can exceed the original PNG's size for complex or photographic images. Try lowering the quality slider (with Lossless off) if file size matters more than pixel-perfect accuracy.

Can I convert multiple PNG files at once?

Yes. Select or drag in more than one PNG at a time and the tool converts all of them together using your current quality/lossless settings, then lists each result with its own thumbnail and Download button. There's no single ZIP download - each converted file downloads individually.

Is anything uploaded to Fixoona's servers?

No. The PNG is read locally with the FileReader API and converted with the Canvas API entirely inside your browser tab.
