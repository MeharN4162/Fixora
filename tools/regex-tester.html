How to Test a Regular Expression

  1. Type your regex pattern into the pattern field (without the surrounding slashes), or click one of the common-pattern buttons (Email, URL, US Phone Number, IPv4 Address) to load a ready-made one.
  2. Choose which flags to apply — global (g) is on by default so every match gets highlighted, not just the first.
  3. Paste or type your test string in the box below.
  4. Matches highlight live as you type, with numbered and named capture groups listed underneath.
  5. To preview a find-and-replace, type a replacement string (like $1-$2) in the Replacement field — the resulting text appears in the "Replaced text" box, updated live.

Frequently Asked Questions

Which regex flavor does this tester use?

It uses your browser's native JavaScript regex engine (the RegExp object), so it behaves exactly like the regex you'd write in a real JavaScript project — not PCRE, Python's re, or another language's flavor, which can have subtly different syntax.

Why do I need the "g" flag to see all matches highlighted?

Without the global flag, JavaScript's regex engine stops after the first match. The g flag tells it to keep scanning the rest of the string and report every match, which is why it's checked by default here.

What do the numbered groups in the results mean?

Each pair of unescaped parentheses in your pattern creates a capture group. For every match, the tool lists what each group actually captured in that match, numbered in the order the groups appear in your pattern — useful for pulling out specific pieces of a match rather than the whole thing. Named groups, written as (?<name>...), are listed by name alongside the numbered ones.

How does replace mode work?

Type a replacement string in the Replacement field to turn on replace mode. The tool runs your test string through JavaScript's real String.replace(), so $1, $2, etc. insert what each numbered group captured, $<name> inserts a named group, and $& inserts the whole match. If the g flag is checked, every match gets replaced; otherwise only the first one does — exactly like native JavaScript.

What are the common pattern buttons for?

They're ready-made regex snippets for things people test constantly — email address, URL, US phone number, and IPv4 address. Clicking one loads that pattern straight into the Pattern field so you can see it match against your text immediately, or use it as a starting point to tweak.

Why does my pattern show an error instead of running?

The pattern you typed isn't valid JavaScript regex syntax — commonly an unescaped special character, an unclosed bracket or group, or an invalid flag combination. The error message shown is JavaScript's own SyntaxError text, which usually points at what's wrong.

Is my text or pattern sent anywhere?

No — matching runs entirely in your browser using JavaScript's built-in regex engine. Nothing you type is transmitted anywhere.
