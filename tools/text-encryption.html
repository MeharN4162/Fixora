Text Encryption

Encrypt or decrypt text with a password using real AES-256-GCM encryption.

🔒

How to Encrypt or Decrypt Text

  1. Choose "Encrypt" or "Decrypt" using the pills.
  2. Paste your text (or, for decrypting, the encrypted output from before).
  3. Enter the password to use.
  4. Click the button, then copy the result.

Frequently Asked Questions

Is this real encryption, or something like ROT13 or Base64?

It's real encryption — AES-256-GCM, a modern, widely trusted encryption standard, performed using your browser's built-in Web Crypto API. This is fundamentally different from ROT13 or Base64, which are simple, reversible encodings that provide no actual security and can be undone by anyone with no password required.

What happens if I forget the password I encrypted something with?

The text can't be recovered. There's no password reset, backdoor, or master key — the encryption key is derived directly from your password and nothing else is stored anywhere. This is the intended, correct behavior of real encryption; losing the password means losing access to the data, by design.

Is my text or password ever sent to a server?

No. Encryption and decryption both happen entirely inside your browser using the Web Crypto API — neither your plain text, your password, nor the encrypted result is ever transmitted anywhere.

Why does the encrypted output look different every time, even with the same text and password?

A new random salt and initialization vector (IV) are generated for every encryption, then bundled with the ciphertext in the output. This is a deliberate, standard security practice — it prevents identical plaintext from ever producing identical ciphertext, which would otherwise leak information to an observer.
