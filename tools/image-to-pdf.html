How to Convert Images to PDF

  1. Upload one or more JPG or PNG images (click or drag) — add as many as you like.
  2. Use the up/down arrow buttons on each file in the list to put them in the order you want them to appear as pages.
  3. Choose a Page Size: "Fit to Image" makes each page exactly the image's pixel dimensions, or pick A4/US Letter to center each image on a standard page.
  4. Click "Create PDF" and download the result.

Frequently Asked Questions

What image formats can I use?

Only JPG and PNG. The upload input and the file-handling code both filter to image/jpeg and image/png, so other formats like WebP, GIF, or HEIC won't be added even if selected.

What's the difference between "Fit to Image" and choosing A4 or US Letter?

"Fit to Image" creates a PDF page sized exactly to each image's pixel dimensions, so there's no border or padding. A4/US Letter instead creates a standard-sized page and centers your image inside it at about 92% scale, leaving a small margin.

Can I mix images of different sizes and orientations in one PDF?

Yes. Each image becomes its own page, so a landscape photo followed by a portrait document works fine with "Fit to Image" — each page will simply have different dimensions. With A4/US Letter, every page is the same fixed size regardless of the image's shape.

Does converting images to PDF reduce their quality?

No — your original JPG or PNG bytes are embedded directly into the PDF rather than being re-encoded, so image quality is unchanged.

Can I remove an image after adding it?

Yes, click the ✕ button next to any file in the list to remove it before creating the PDF.
