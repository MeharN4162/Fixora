Countdown Timer & Stopwatch

Set a countdown for any duration, or track elapsed time with a stopwatch and lap splits.

How to Use the Countdown Timer & Stopwatch

  1. Choose "Countdown Timer" or "Stopwatch" from the pill toggle at the top.
  2. For the countdown timer, set hours, minutes, and seconds, then click "Start" — use "Pause" and "Reset" to control it.
  3. For the stopwatch, click "Start" to begin timing, "Lap" to record a split without stopping, and "Reset" to clear.
  4. Watch the large display update live; the countdown timer alerts "Time's up!" when it reaches zero.

Frequently Asked Questions

Does the countdown timer keep running if I switch to another browser tab?

Yes — the timer tracks the actual end time using the system clock rather than just counting down a fixed number of ticks, so it stays accurate even if the tab is backgrounded or the browser throttles JavaScript timers.

What do the numbers in parentheses mean next to each lap in the stopwatch?

Each lap shows the split time (time since the previous lap) first, followed by the total elapsed time in parentheses — so you can see both how fast that segment was and your overall running time.

Can I set a countdown for more than 24 hours?

Yes, the Hours field accepts any number, not just 0-23, so you can set very long countdowns, like 48 hours, if needed.

Will the timer or stopwatch keep running if I close the browser tab?

No — both run entirely in your browser and reset once the page or tab is closed; there's no background or server-side timer, so keep the tab open while it counts.

What happens if I click Start on the countdown timer without setting a duration?

If the total duration is zero, the tool shows a message asking you to set a duration greater than zero instead of starting.
