PDF Page Numbers

Add page numbers to every page of a PDF — choose the position, format, and starting number.

How to Add Page Numbers to a PDF

  1. Upload your PDF.
  2. Choose a Position (six options: top/bottom paired with left/center/right) and a Format ("1, 2, 3…", "Page 1, Page 2…", "1 of 10, 2 of 10…", "Page 1 of 10…", or "1 / 10…").
  3. Set the Start At number if you don't want numbering to begin at 1, and adjust the Font Size slider.
  4. Check "Skip first page" if your PDF has a cover or title page you don't want numbered — the first page is left blank and your Start At number appears on the second page instead.
  5. Click "Add Page Numbers" and download the numbered PDF.

Frequently Asked Questions

Can I make page 1 start at a number other than 1?

Yes — the Start At field sets whatever number the first page should show, and every page after it counts up sequentially from there. This is useful if you're numbering a chapter that continues from a previous document.

What does the "1 of 10, 2 of 10…" format actually count?

The total shown is calculated from your Start At number plus the number of pages that actually get numbered, not just the raw page count — so if you start at 5 on a 10-page document, it will show "5 of 14," reflecting the numbering range rather than the physical page total. If Skip First Page is also checked, one fewer page gets numbered, so the total drops by one too — starting at 5 on a 10-page document with the first page skipped shows "5 of 13" on page 2.

Will the numbers overlap with my existing page content?

They're placed at a fixed margin from the page edge depending on the position you choose, so on pages with content that already extends close to that edge, there's a chance of visual overlap — if that happens, try a smaller font size or a different position.

Can I add page numbers to only some pages, like skipping a cover page?

You can skip exactly the first page — check "Skip First Page" and it's left blank while your Start At number appears starting on page 2 instead. There's no option to exclude other individual pages beyond that; every page after the first (or every page, if the box is unchecked) gets the same position, format, and sequential numbering.

Does adding page numbers affect the PDF's original content?

No — page numbers are drawn as new text on top of each existing page; nothing already on the page is removed or altered.

What page number formats can I choose from?

Five: "1, 2, 3…" (a bare number), "Page 1, Page 2…", "1 of 10, 2 of 10…", "Page 1 of 10…", and "1 / 10…" — pick whichever matches your document's style.
