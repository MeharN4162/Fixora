Frequently Asked Questions

What's the difference between the decimal and binary standards?

The decimal standard (used by storage manufacturers) defines 1 KB as 1,000 bytes, 1 MB as 1,000 KB, and so on. The binary standard (how operating systems and file browsers usually calculate size) defines 1 KiB as 1,024 bytes — the same prefixes, but a meaningfully different number.

Why does my hard drive show less storage than advertised?

This is exactly the decimal-vs-binary difference — a drive advertised as 1 TB (1,000,000,000,000 bytes, the decimal definition) shows up as roughly 931 GiB in an operating system that reports size using the binary (1,024-based) standard.

What's the difference between a bit and a byte?

A byte is 8 bits. Internet speeds are usually advertised in bits per second (like Mbps), while file sizes are usually shown in bytes — which is why a "100 Mbps" connection downloads at roughly 12.5 megabytes per second, not 100.

Is my data sent anywhere?

No — the conversion happens entirely in your browser using JavaScript, so nothing you enter is ever sent to a server.
