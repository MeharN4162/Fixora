Find and Replace Text Tool

Bulk find and replace text, with case-sensitive, whole-word, and regex options.

How to Find and Replace Text

  1. Paste your text into the box.
  2. Enter what to find and what to replace it with.
  3. Turn on case-sensitive, whole-word, or regex matching as needed — the result and match count update live.
  4. Copy the result with the "Copy Result" button.

Frequently Asked Questions

What does "Whole word only" do?

It only matches your search text when it appears as a complete word, not as part of a longer word — so searching for "cat" with this on won't match inside "category," but will still match the standalone word "cat."

How does the regular expression option work?

When enabled, the "Find" field is treated as a JavaScript regular expression pattern instead of literal text, letting you use patterns like \d+ to match numbers or use capture groups like ($1) in the replacement field to reuse matched text. If your pattern is invalid, the tool shows an error instead of guessing.

Does this replace only the first match or every match?

Every match, by default — turn off "Replace all occurrences" if you only want the first match in the text replaced.

Is my text sent anywhere?

No — the find-and-replace operation runs entirely in your browser using JavaScript, so your text is never sent to a server.
