How to Compress an Image

  1. Click the upload area or drag in a JPG or PNG file.
  2. Choose "Manual Quality" and drag the slider (10–95%), or choose "Target File Size" and type a KB target — the tool searches for the highest quality that still fits.
  3. Pick an Output Format: JPG or WebP.
  4. Check the Original Size, Compressed Size, and Saved percentage stats, then click "Download Compressed Image".

Frequently Asked Questions

What output formats can I compress to, and does that change transparency?

You can choose JPG or WebP as the output format regardless of what you uploaded. JPG always fills transparent areas with white since it can't store transparency; WebP supports transparency, so a transparent PNG compressed to WebP keeps its transparent areas intact.

What does the Compression percentage actually control?

It's the JPEG or WebP quality value passed to the browser's canvas encoder - lower numbers mean more aggressive compression (smaller file, more visible artifacts) and higher numbers stay closer to the original image quality.

How does Target File Size mode work?

Instead of you picking a quality percentage, you type a target size in KB and the tool runs a binary search: it repeatedly re-encodes your image at different quality levels in your browser until it finds the highest quality that still fits under your target, then uses that result. If even the lowest quality still exceeds your target, it uses the smallest file it could produce and tells you so.

My image barely got smaller - why?

If the tool reports minimal size reduction, your image was likely already well-optimized or the content doesn't compress much further at the chosen quality (flat colors and simple graphics compress differently than complex photos). Try lowering the Compression slider, or switching to Target File Size mode, for a bigger reduction.

Does this tool resize my image to make it smaller?

No - dimensions stay exactly the same; only the compression level changes. If you also want to change pixel dimensions, use Fixoona's Image Resizer instead.

Is my file uploaded to a server to be compressed?

No. Compression happens locally using the Canvas API's encoder with a quality parameter, including all the target-size binary search attempts - your image is never sent anywhere.
