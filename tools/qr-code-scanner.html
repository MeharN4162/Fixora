How to Scan a QR Code from an Image

  1. Click the upload area or drag in an image file that contains a QR code — a photo, screenshot, or exported PNG all work.
  2. The tool draws the image onto a canvas and scans its pixels locally for a QR pattern.
  3. If a code is found, the decoded text appears in the field below — click "Copy" to copy it, or click the link if it's a URL.
  4. If no code is found, try a clearer or more tightly cropped photo of just the QR code.

Frequently Asked Questions

Does this tool decode QR codes without uploading my image to a server?

Yes — the image is decoded entirely in your browser using a local JavaScript library (jsQR); your photo is never uploaded or sent anywhere.

What happens if no QR code is found in my image?

You'll see a clear message telling you no QR code was detected, rather than a guessed or fake result — try a clearer, more cropped, or higher-resolution photo containing just the code.

What image formats can I upload?

Any common image format your browser can display — JPG, PNG, WebP, and more — since the tool draws your file onto a canvas and reads its pixel data directly, rather than relying on the file extension.

Can this scan a QR code directly from my camera?

No — this tool only decodes QR codes from an image file you upload or drag in; it doesn't request access to your camera for a live scan.

Why does it show the decoded text as a clickable link sometimes?

When the decoded text starts with http:// or https://, the tool also displays it as a clickable link so you can open it directly, in addition to showing the raw text in a field you can copy.
