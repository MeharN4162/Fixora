How to Scan a QR Code from an Image

  1. Click the upload area or drag in an image file that contains a QR code — a photo, screenshot, or exported PNG all work.
  2. The tool draws the image onto a canvas and scans its pixels locally for a QR pattern.
  3. If a code is found, its content type is detected automatically — links, Wi-Fi logins, contact cards (vCards), email addresses, and phone numbers each get parsed fields and a quick-action button, like Open link, Copy Wi-Fi password, or Call, alongside the raw decoded text you can copy.
  4. Every successful scan is added to the Scan History list below, so you can revisit or copy earlier results from the same session — click "Clear" to reset it.
  5. If no code is found, try a clearer or more tightly cropped photo of just the QR code.

Frequently Asked Questions

Does this tool decode QR codes without uploading my image to a server?

Yes — the image is decoded entirely in your browser using a local JavaScript library (jsQR); your photo is never uploaded or sent anywhere.

What happens if no QR code is found in my image?

You'll see a clear message telling you no QR code was detected, rather than a guessed or fake result — try a clearer, more cropped, or higher-resolution photo containing just the code.

What image formats can I upload?

Any common image format your browser can display — JPG, PNG, WebP, and more — since the tool draws your file onto a canvas and reads its pixel data directly, rather than relying on the file extension.

Can this scan a QR code directly from my camera?

No — this tool only decodes QR codes from an image file you upload or drag in; it doesn't request access to your camera for a live scan.

What does the tool do differently for Wi-Fi codes, contact cards, and links?

It automatically detects the content type and shows relevant details instead of just raw text: Wi-Fi QR codes display the parsed network name, security type, and password with a one-click copy button; contact card (vCard) QR codes display the parsed name, organization, phone, and email with Call and Email buttons; links show an "Open link" button; and email or phone QR codes show a ready-to-use email or call button. The raw decoded text is always shown too, so you can copy it directly.

Can it read Wi-Fi QR codes and show me the password?

Yes — QR codes generated in the standard WIFI: format are parsed into the network name (SSID), security type, and password, each shown as text plus one-click copy buttons, so you can join the network without retyping anything.

Can it read contact card (vCard) QR codes?

Yes — QR codes containing a standard vCard (starting with BEGIN:VCARD) are parsed into the contact's name, organization, title, phone number(s), and email(s), with quick Call and Email buttons for the first phone number and email address found.

What is the Scan History for?

It keeps a list of your decoded QR codes from this browser tab, each with its detected type and a Copy button, so you can revisit earlier scans without re-uploading the image. It only exists in memory for the current page session and clears if you reload the page or click "Clear".
