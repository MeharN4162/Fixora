How to Make a Meme

  1. Click the upload area or drag in a JPG, PNG, or WebP image to use as your meme's background.
  2. Type into the default Top Text and Bottom Text boxes, or click "+ Add Text Box" for more — every box is shown in bold, uppercase lettering with an outline automatically.
  3. Click and drag any text directly on the image to position it exactly where you want.
  4. Use each box's Font dropdown, Size slider, and Text/Outline color pickers to style it however you like.
  5. Click "Download Meme" to save the finished image as a PNG.

Frequently Asked Questions

Why does my text automatically appear in ALL CAPS?

The tool converts the text in every text box to uppercase automatically, matching the classic meme text style - you don't need to type in caps yourself.

What happens if my text is too long to fit?

Each text box wraps long captions onto multiple lines automatically, and if the block still doesn't fit within about 92% of the image's width and 90% of its height, it progressively shrinks that box's font size until every line fits without spilling past the edges of the image.

Can I use a custom font instead of the classic meme style?

Yes - each text box has its own Font dropdown with five real, working styles: Impact (the classic meme look), Arial Black, Comic Sans MS, Space Grotesk, and Georgia. Every box can use a different font, and the bold black-outline treatment is still applied automatically for readability.

Can I change the text color or outline color?

Yes - each text box has its own Text Color and Outline Color pickers, so you're not limited to the classic white-with-black-outline look, though that's still the default for every new box.

Can I move the text anywhere on the image?

Yes - click and drag any text box directly on the meme image to reposition it exactly where you want. Dragging is constrained to inside the image so a box can't be lost off the edge, and each box also has a reset button that returns it to its starting position.

Can I add more than two lines of text?

Yes - click "+ Add Text Box" to add as many independent text boxes as you like, each with its own text, position, font, size, and colors, and remove any box you no longer need with its ✕ button.

What file format does my meme download as?

Always PNG, produced with canvas.toBlob() using image/png - regardless of whether your source image was a JPG, PNG, or WebP.

Is my image or text sent anywhere while I'm editing?

No. Everything - drawing the image, rendering the text, and generating the download - happens locally on a canvas element in your browser.
