PDF Watermark

Stamp a custom text watermark across every page of a PDF — perfect for marking drafts or protecting shared copies.

How to Add a Watermark to a PDF

  1. Upload your PDF.
  2. Type your watermark text (defaults to "DRAFT" — try "CONFIDENTIAL" or your company name).
  3. Adjust Size, Opacity, and Angle with the sliders, and pick a color with the color picker — the values update live next to each label.
  4. Click "Add Watermark" and download the watermarked PDF.

Frequently Asked Questions

Where is the watermark placed on the page?

Dead center of every page, rotated to the angle you chose. The tool calculates the text's true visual center (not just its baseline) so the watermark stays centered even when tilted at an angle like the default 45°.

Can I put the watermark in a corner instead of the center?

Not currently — this tool always centers the watermark on each page. If you need a specific position like a bottom-right stamp, the PDF Page Numbers tool supports six fixed positions, though it's designed for numbers rather than arbitrary text.

Will the watermark cover up my document's content?

It can, depending on your opacity setting — the default is a light 30% opacity so text underneath stays readable, but you can push it up to 100% for a bold, fully opaque stamp if that's what you want.

Is the watermark applied to every page, including a title page?

Yes, every single page in the document gets the same watermark text, size, opacity, angle, and color — there's no way to skip specific pages in this tool.

Can someone remove the watermark from the PDF I create?

The watermark is drawn as real text directly onto each page's content, similar to what most watermarking tools do, so it isn't cryptographically locked — a determined person with PDF editing software could still remove it. Treat it as a visible deterrent rather than a security measure.
