User Agent Parser

Parse any user agent string into browser, engine, OS, and device details.

How to Parse a User Agent String

  1. Paste any user agent string, or click "Use My Browser's User Agent."
  2. The browser, engine, OS, and device details appear instantly.

Frequently Asked Questions

What is a user agent string?

It's a piece of text every browser sends with its requests that identifies the browser, its version, the operating system, and the device — websites use it to serve appropriately formatted pages or gather basic analytics.

Why does my browser's user agent mention other browsers, like Safari or Gecko?

For historical compatibility reasons, browsers include references to older or competing browser engines in their user agent strings so that websites built to check for those tokens still work correctly — this is why Chrome's user agent string actually contains the word "Safari."

How accurate is user agent parsing?

This tool uses UAParser.js, a widely used open-source parsing library, which handles the vast majority of real-world browsers and devices correctly. That said, user agent strings can be spoofed or customized, so parsing them is never a guaranteed way to identify a browser with total certainty.

Is the user agent string sent anywhere when I use this?

No — the parsing happens entirely in your browser using JavaScript, so nothing you enter (or your own detected user agent) is ever sent to a server.
