Morse Code Translator

Translate text to Morse code and back, and actually hear it played back.

How to Translate Morse Code

  1. Choose a direction with the pills.
  2. Type your text or Morse code into the input box.
  3. The translated result appears instantly.
  4. Click "▶ Play Morse Audio" to hear it as real Morse code beeps.

Frequently Asked Questions

How are letters separated from words in the Morse output?

Each letter's dots and dashes are separated by a single space, and a forward slash ( / ) marks the gap between whole words — this is the standard written convention for Morse code.

What characters does this support?

All 26 letters, the digits 0–9, and the most common punctuation marks (period, comma, question mark, apostrophe, and a few others) using the standard International Morse Code chart.

How does the playback actually work?

It uses your browser's Web Audio API to generate a real tone, switching it on and off for durations matching standard Morse timing ratios — a dash lasts three times as long as a dot, with proportionally longer gaps between letters and words.

Is my text sent anywhere?

No — translation and playback both happen entirely in your browser using JavaScript, so nothing you type is ever sent to a server.
