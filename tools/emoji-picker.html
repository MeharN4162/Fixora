Emoji Picker

Search all 2,392 standard emoji (including every skin-tone variant) by name or keyword, browse them in clear category sections — Smileys, People, Animals, Food, Activities, Travel, Objects, Symbols, Flags, and Hearts — and click any of them (or navigate the grid with your keyboard) to copy it straight to your clipboard, either as the emoji itself or as :shortcode: text.

How to Find and Copy an Emoji

  1. Type a word into the search box — like "dog", "heart", or "pizza" — to filter across all 2,392 emoji by name or keyword.
  2. Or click a category pill (Smileys, People, Animals, Food, Activities, Travel, Objects, Symbols, Flags, Hearts) to browse one section at a time, or "All" to see every section with its own heading.
  3. Click any emoji in the grid to copy it to your clipboard — or Tab into the grid and use the arrow keys (or Home/End) to move between emoji and Enter or Space to copy the focused one.
  4. Turn on "Copy as :shortcode: text" if you'd rather copy a colon-wrapped text label like :grinning_face: instead of the emoji character itself.
  5. Paste it wherever you need it — a chat, a document, a caption, anywhere.

Frequently Asked Questions

How many emoji are included in this picker?

This picker includes 2,392 standard emoji, organized into clear category sections: Smileys, People, Animals, Food, Activities, Travel, Objects, Symbols, Flags, and Hearts. That includes all 5 official skin-tone variants for every emoji that supports one (waves, hands, people, and more). It leaves out the gendered profession combinations (like separately listing man teacher and woman teacher for every profession) since that alone would add several thousand near-duplicate entries — the neutral base form of each is included instead.

How does clicking an emoji copy it?

Clicking any emoji button copies that exact character to your clipboard using your browser's Clipboard API, so you can paste it straight into a message, document, or post.

Why doesn't a particular emoji show up in my search?

Search matches against each emoji's name and a short list of keywords, so if a search term isn't covered, try a more common word for what you're looking for — the emoji itself might use a different official name than you expect.

Will the emoji look the same on every device?

No — the underlying character is identical everywhere, but its exact appearance depends on your device and app's emoji font, so the same emoji can look a little different on, say, an iPhone versus a Windows PC.

Do I need to install anything to use this?

No — everything runs directly in this page using your browser's built-in emoji rendering and Clipboard API; there's nothing to download or install.

Can I copy an emoji as a text shortcode instead of the character itself?

Yes — turn on "Copy as :shortcode: text" above the grid and clicking an emoji will copy a colon-wrapped, underscore-separated version of its name (like :grinning_face: for 😀) instead of the emoji character itself. This is generated directly and consistently from each emoji's own name in this picker, so it won't necessarily match the shortcode syntax used by a specific chat app, but it's always a predictable, unique text label for that emoji.

Can I use the keyboard to browse and copy emoji?

Yes — Tab into the emoji grid, then use the arrow keys (or Home/End) to move between emoji, and press Enter or Space to copy whichever one is focused, all without touching your mouse.
