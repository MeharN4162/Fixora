Palindrome Checker

Check if a word, phrase, or number reads the same forwards and backwards.

How to Check a Palindrome

  1. Type any word, phrase, or number.
  2. The result appears instantly, ignoring spaces, punctuation, and case.

Frequently Asked Questions

What counts as a palindrome here?

Any text that reads the same forwards and backwards once spaces, punctuation, and capitalization are ignored — so "A man, a plan, a canal: Panama" counts as a palindrome, the same way it would if you were checking it by hand.

Does it work for numbers too?

Yes — a number like 12321 is checked the same way, digit by digit, since digits are treated just like letters for this comparison.

Why are spaces and punctuation ignored?

Classic palindrome phrases are traditionally judged on their letters alone — "Never odd or even" is considered a palindrome even though the spaces themselves obviously aren't symmetric, only the letters are.

Is my text sent anywhere?

No — the check happens entirely in your browser using JavaScript, so nothing you type is ever sent to a server.
