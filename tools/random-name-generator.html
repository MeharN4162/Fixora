Random Name Generator

Generate random names for people, usernames, teams, projects, fantasy characters, businesses, pets, or babies — instantly and for free.

How to Generate Random Names

  1. Choose what you need a name for: Person Name, Username, Team Name, Project / Codename, Fantasy Character, Business / Company Name, Pet Name, Baby Name (Boy), or Baby Name (Girl).
  2. Optionally pick a letter from "Start with letter" to only generate names that begin with that letter for the chosen category.
  3. Drag the slider to set how many results you want, from 1 to 20.
  4. Click Generate Names for a fresh batch — a batch also loads automatically the first time the page opens.
  5. Click Copy next to any single name to copy just that one, or click Copy All to copy the whole batch as a list.
  6. Every name you generate is added to the History list below, so you can scroll back and re-copy earlier results — click Clear History to reset it for this session.

Frequently Asked Questions

How many unique names can each category actually produce?

Person Name and Fantasy Character each combine 30 first/given names with 20 last names or surnames for 600 possible combinations. Username combines 20 adjectives, 20 nouns, and a random number up to 998 for roughly 400,000 combinations. Business/Company Name combines 20 + 20 + 15 word lists for 6,000 combinations. Team Name and Project/Codename each combine 20 adjectives with 20 nouns for 400 combinations. Pet Name draws from a list of 40 names, and Baby Name (Boy) and Baby Name (Girl) each draw from a list of 30 names.

Can the generator produce duplicate names in the same batch?

No — it keeps track of names already generated in that batch and retries (up to 30 attempts per requested name) to avoid repeats. If you request more names than a category (or a letter-filtered subset of it) has unique combinations for, you may end up with fewer results than the slider asked for.

Are these names guaranteed to be available as real usernames or domains?

No. The generator only combines words from its built-in lists — it doesn't check availability on any social platform, domain registrar, or app store, so you'll need to verify the name is free wherever you plan to use it.

Does the generator pull names from an online database or API?

No. All names are built client-side from a small set of fixed word lists (first names, last names, adjectives, nouns, fantasy names, business words, pet names, and baby names) baked directly into the page's JavaScript — nothing is fetched from a server.

Why do I sometimes see similar names across different batches?

Categories built from small word lists — Team Name, Project/Codename, Pet Name, and the two Baby Name lists — have only a few hundred (or, for Pet and Baby Names, a few dozen) possible outputs, so generating several batches in a row can surface names you've seen before. Username and Business/Company Name draw from much larger pools, so repeats are far less likely.

What does the "Start with letter" option do?

It filters the selected category's underlying word list down to only the entries whose first letter matches your choice, then picks randomly from just that filtered subset using the same crypto.getRandomValues() source as every other pick — so every result is guaranteed to start with the letter you chose. Some letters have no matches in a given category's list; if that happens, you'll see a message instead of results.

Is there a history of the names I've generated?

Yes. Every name you generate is added to the History list below the results, most recent first, capped at the last 40 entries. Click Copy next to any past entry to copy it again, or click Clear History to empty the list. It only exists in your browser tab's memory for the current session — reloading or closing the page clears it, and nothing is ever sent to a server.

Can I copy all the generated names at once?

Yes — click Copy All above the results to copy every name in the current batch to your clipboard as a newline-separated list. You can also click Copy next to any single name, in the results or in History, to copy just that one.
