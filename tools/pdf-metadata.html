How to Edit or Strip PDF Metadata

  1. Upload your PDF — its current Title, Author, Subject, Keywords, Creator, Producer, and Created date load automatically, along with a read-only page count. The Language field starts blank since it can only be written, not read back.
  2. Edit any of the text fields, set a Language code, or adjust the Created date — use "Set Created to Now" for a quick timestamp. The Modified date can't be set manually; the PDF library always stamps it with the exact moment you save.
  3. Click "Save Changes" to apply your edits, or "Strip All Metadata" to clear the Title/Author/Subject/Keywords/Creator/Producer fields at once — the Created date and any existing Language tag are left as-is.
  4. Download the updated PDF.

Frequently Asked Questions

What's the difference between "Save Changes" and "Strip All Metadata"?

"Save Changes" writes whatever is currently in the Title/Author/Subject/Keywords/Creator/Producer/Language fields — including any edits you made — plus the Created date if you changed it. "Strip All Metadata" clears the Title, Author, Subject, Keywords, Creator, Producer fields to blank and saves, removing that identifying information from the PDF entirely; it also resets the Language and Created fields in the form, but since those two are only written when you've actually entered a value, the PDF's existing creation date and any existing language tag are left untouched by Strip. In both cases the Modified date is stamped automatically to the exact moment you save — the PDF library controls that field and it can't be set manually.

Can I edit the Created and Modified dates?

You can edit the Created date — it loads as an editable field pre-filled from the PDF, and you can also click "Set Created to Now" for a quick timestamp. The Modified date can't be set manually: the PDF library always overwrites it with the exact moment you click "Save Changes," and the actual stamped value is shown after saving.

Why would I want to strip a PDF's metadata?

Metadata can quietly reveal information like the author's name, the software used to create the file, or when it was made — details you might not want attached to a document before sharing it publicly.

How do I enter multiple keywords?

Type them into the Keywords field separated by commas — the tool splits on commas and trims whitespace around each one when saving.

Does editing metadata change the PDF's actual page content?

No — only the document-level metadata fields are touched. The pages, text, and images inside the PDF are saved exactly as they were.

Can I set the PDF's language metadata?

Yes — enter a language code such as en, en-US, fr, or de in the Language field and click Save Changes. This tool can only write that field, not read an existing one back out, so it always starts blank; leaving it blank and saving keeps whatever language (if any) the PDF already had, since a blank value is never written unless you touch the field.
