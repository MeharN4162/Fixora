WiFi QR Code Generator

Generate a scannable QR code so guests can join your WiFi without typing a password.

Download PNG

How to Use the WiFi QR Code Generator

  1. Enter your network name and password.
  2. Choose the security type (WPA/WPA2 is standard for most home networks).
  3. Download the QR code and print it or share it — scanning it connects instantly.

Frequently Asked Questions

How does scanning this actually connect someone to WiFi?

This QR code encodes your network name and password in a standard format that iPhone and Android camera apps recognize automatically — scanning it prompts the phone to join the network directly, without anyone having to type the password by hand.

Is my WiFi password sent anywhere when I generate this?

No — the QR code is generated entirely in your browser, so your network name and password never leave your device or get sent to a server.

Will this work with any phone?

Most modern iPhones (iOS 11+) and Android phones (10+) recognize WiFi QR codes directly in their built-in camera app. Older devices may need a separate QR scanner app instead of the native camera.

What does the "hidden network" option do?

Turn it on only if your WiFi network doesn't broadcast its name publicly — it tells the scanning device to search for a hidden network with the exact name you entered instead of picking it from a visible list.
