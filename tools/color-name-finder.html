Color Name Finder

Find the nearest standard CSS color name for any color you pick.

How to Find a Color Name

  1. Pick or type a color.
  2. The closest matching standard CSS color name appears instantly.

Frequently Asked Questions

Where does the list of color names come from?

All 147 official CSS extended color keywords, like "CornflowerBlue" and "MediumSeaGreen" — the exact same standardized named colors browsers recognize when used directly in CSS.

How is the "nearest" match determined?

By the straight-line (Euclidean) distance between your color and each named color in RGB space — the named color with the smallest distance is shown as the closest match. This is a simple, common approach, though it doesn't perfectly account for how the human eye perceives color differences.

Will the exact color I enter always have a matching name?

Only if it's one of the 147 named colors exactly — for any other color, this tool finds and shows the closest named color along with exactly how different it is.

Is my data sent anywhere?

No — the entire lookup happens locally in your browser using JavaScript, so nothing is ever sent to a server.
