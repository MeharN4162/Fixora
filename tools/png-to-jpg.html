How to Convert a PNG to JPG

  1. Click the upload area or drag in one or more PNG files — select multiple files at once to batch convert.
  2. Drag the "JPG Quality" slider to balance file size against visual quality (default is 90%), and pick a Background Color to replace transparent areas (default is white).
  3. With a single file, the preview and PNG/JPG/Dimensions stats update automatically as you adjust settings; with multiple files, each result appears in a list with its own thumbnail.
  4. Click "Download JPG" for a single file, or the "Download" button next to each result in batch mode.

Frequently Asked Questions

What happens to transparent areas in my PNG?

JPEG has no support for transparency, so before drawing your image the tool fills the canvas with your chosen Background Color first - any transparent or semi-transparent pixels in the PNG take on that color in the exported JPG. It defaults to white but can be changed to anything.

Can I use a background color other than white?

Yes. Use the Background Color picker above the quality slider to fill transparent and semi-transparent PNG areas with any color you like before the JPG is encoded - white just remains the default since it suits most photos and documents.

Can I convert multiple PNG files at once?

Yes. Select or drag in more than one PNG at a time and the tool converts all of them together using your current quality and background color settings, then lists each result with its own thumbnail and Download button. There's no single ZIP download - each converted file downloads individually.

What does the Quality slider actually control?

It sets the JPEG compression quality passed to the browser's canvas encoder, from 40% (smaller file, more visible compression artifacts) up to 100% (larger file, closer to the source). The stat row shows the exact resulting file size so you can judge the trade-off directly.

Why does the preview update automatically when I move the slider?

The tool re-encodes the image (or images, in batch mode) about 120ms after you stop dragging the quality slider or changing the background color, and swaps in the new preview and file size, so you can fine-tune settings without clicking a separate convert button each time.

Will this remove any metadata from my PNG?

Yes. Because the image is redrawn onto a canvas and re-encoded as a new JPEG, any metadata the PNG might have carried is not preserved in the output file.

Does this tool upload my image anywhere?

No. Everything happens locally using the File and Canvas APIs in your browser - your PNG is never sent to a server.
