How it works: each page is re-rendered and desaturated, then rebuilt into a new PDF. Note: text in the output is no longer selectable, since pages are flattened to images.

How to Convert a PDF to Grayscale

  1. Upload your PDF.
  2. Choose an Output Quality level: High quality for the sharpest result, Balanced for a good middle ground, or Smaller file for the most compact output.
  3. Click "Convert to Grayscale".
  4. Check the Original Size / New Size stats, then download the grayscale PDF.

Frequently Asked Questions

Will my PDF's text still be selectable after converting to grayscale?

No. Like the PDF Compressor, this tool re-renders every page as an image, desaturates the pixels, and re-encodes it as a JPEG before rebuilding the PDF — so any selectable text becomes part of a flattened image and can no longer be copied or searched.

How is the grayscale conversion calculated?

Each pixel's red, green, and blue values are combined using the standard luminance-weighted formula (roughly 30% red, 59% green, 11% blue) rather than a simple average, which better matches how the human eye perceives brightness.

Why does the file size change even though I just removed color?

The size change comes from the same re-rendering and JPEG re-encoding process used for compression, not from the grayscale conversion itself — that's also why there's a quality-level selector, since it controls the same scale/quality tradeoff as the PDF Compressor.

Is this the same as making a PDF black-and-white / 1-bit?

No — this produces true grayscale, with a full range of gray tones (like a black-and-white photo), not a pure black-and-white (1-bit) result where every pixel is either fully black or fully white.

Does this help with printing costs?

It can — many printers charge more, or use more toner/ink, for pages containing any color, so converting a PDF to grayscale before printing can be cheaper even if the file itself doesn't get much smaller.
