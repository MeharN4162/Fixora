Lottery Number Generator

Generate random lottery numbers for popular formats or a custom range.

How to Generate Lottery Numbers

  1. Pick a preset (Powerball, Mega Millions, EuroMillions) or choose Custom for any range and count.
  2. Click "Generate Numbers" for a fresh, genuinely random set anytime.

Frequently Asked Questions

Does this improve my odds of winning?

No — every combination of numbers has exactly the same odds regardless of how it's chosen. This tool doesn't predict or influence real lottery draws in any way; it just gives you a genuinely random, unbiased pick instead of numbers you might otherwise choose non-randomly (like birthdays, which cluster many players onto the same popular numbers).

How random are these numbers, really?

Numbers are generated using the Web Crypto API's crypto.getRandomValues() with rejection sampling, so every number in range has an exactly equal chance of being picked, with no bias — the same quality of randomness used for cryptographic keys, not the weaker Math.random().

Do the presets match the real official number ranges?

Yes, as of when this tool was built — Powerball draws 5 numbers from 1–69 plus 1 Powerball from 1–26, Mega Millions draws 5 from 1–70 plus 1 Mega Ball from 1–25, and EuroMillions draws 5 from 1–50 plus 2 Lucky Stars from 1–12. Official rules occasionally change, so double-check against the current official rules before treating a preset as authoritative.

Is my data sent anywhere?

No — every number is generated entirely in your browser using JavaScript, so nothing is ever sent to a server.
