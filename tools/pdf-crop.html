How to Crop a PDF

  1. Upload your PDF — page 1 renders as a preview with a draggable crop box already positioned near its edges.
  2. Drag the box to move it, or drag any of the four corner handles to resize it around the area you want to keep.
  3. Click "Crop PDF" once the box covers exactly what you want.
  4. Download the cropped PDF.

Frequently Asked Questions

Does the crop only apply to page 1, or every page?

Every page — you preview and position the crop box on page 1 only, but the same crop area (calculated as a proportion of the page) is applied to all pages when you click Crop PDF, so it works best when every page in your document is the same size.

Does cropping actually delete the content outside the box, or just hide it?

It sets each page's crop box, a standard PDF property that tells viewers and printers which region to display — the underlying content outside that region is technically still in the file, so if you need to fully remove that data (for privacy, for example), cropping alone isn't the right tool.

What happens if my pages are different sizes?

The crop area is stored as a fraction of the page (like "the middle 60% horizontally"), so it's applied proportionally to each page — but if pages vary a lot in size or aspect ratio, the same proportional crop can end up looking different relative to the content on each one.

Can I undo the crop after downloading?

Not within this tool, but since cropping only changes the crop box property rather than deleting page content, another PDF crop or "reset margins" tool may be able to restore the original view if needed.

Why is there no page-by-page preview before I download?

Only page 1 is rendered for the interactive crop selection, to keep the tool fast on longer documents — the crop is then applied proportionally to the rest without rendering each one, since the goal is a single consistent crop across the whole file.
